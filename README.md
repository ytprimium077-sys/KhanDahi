# KHAN दही — FINAL FURNISHED V4

## Local
npm install
npm start
Open http://localhost:3000
Admin: http://localhost:3000/admin

## Render Environment
ADMIN_USER=your_admin_id
ADMIN_PASSWORD=your_password
SESSION_SECRET=long-random-secret
NODE_ENV=production

## Admin
- Brand / Hindi name / tagline
- Phone / email / address
- Hero video / hero image path
- Unlimited products and packages
- Separate image for every package
- Main and offer price
- Add/delete packages
- Customer reviews

## Public site
- Admin-managed contact details actually render on the public site
- Admin-managed brand, Hindi name, tagline, hero video and hero image are applied
- Package selection changes image in-place
- Compact glass price panel updates on the same screen
- Reviews render as transparent glass cards and open in a compact glass popup
